Overview

The API gives your code what a scan gives you in the app: the businesses of an area with their opportunity scores, a read of a website, and drafts and reports from RadiusPilot AI. It takes and answers JSON, over HTTPS, at one address:

Base URLhttps://radiuspilot.com/api/v1/

Opening soon, in beta

The API opens to accepted beta testers first. Each accepted account gets 50 credits to try it, once. Payments aren’t live yet, so more credits can’t be bought yet. Fields may be added during the beta; changes are announced in the changelog.

WhoAccepted beta testers. Request access
Credits50 to try it, from the same balance as the app
Limits30 requests a minute and 1,000 a day, per key
Versionv1, in the address

Get a key

  1. 1

    Join the beta

    Request access on the beta page. An accepted request comes with a beta code.

  2. 2

    Create a key

    Sign in to your account, open API and choose Create key. Name it after where it will run. The first time, paste your beta code.

  3. 3

    Copy it once

    The key is shown once. Keep it in your server’s secrets or a password manager: we store only a hash of it and its first 12 characters, so we can’t show it again.

  4. 4

    Revoke it any time

    On the same page. It stops working at once, and the apps using it with it.

Keep keys on your server

A key spends your credits. Never put one in a web page, an app people download or a public repository. Revoke it if it leaks.

Authentication

Send your key in the Authorization header of every request. Keys start with rp_live_, then 32 random characters.

Header
Authorization: Bearer rp_live_…

A missing, mistyped or revoked key gets 401 unauthorized. Every answer carries an X-Request-Id header: quote it when you write to us about a request.

Credits

Requests spend credits from your account’s balance, the same credits as in the app. A success says what it used and what’s left, in credits:

In every answer that spends credits
"credits": { "used": 10, "left": 40 }
EndpointCredits
GET /v1/account0
POST /v1/businesses/search10
POST /v1/sites/check1
POST /v1/ai/write1
POST /v1/ai/report3
  • A request that fails gives its credits back: a server error, or a service behind it that doesn’t answer.
  • Without enough credits, a request answers 402 not_enough_credits and spends nothing. Nothing is ever charged automatically.
  • What each action costs in the app, and the credit packs, are on the pricing page.

Endpoints

Five endpoints in v1. Paths are relative to the base URL. Requests with a body send JSON with Content-Type: application/json.

  • GET/accountThe key and its balance
  • POST/businesses/searchBusinesses in an area, scored
  • POST/sites/checkCheck a website
  • POST/ai/writeDraft an email or a message
  • POST/ai/reportWrite a report

GET/v1/accountNo credits

The key and its balance. Which key is calling, the credits left on the account and the key’s limits. A good first call to check that a key works.

curl https://radiuspilot.com/api/v1/account \

POST/v1/businesses/search10 credits

Businesses in an area, scored. Every named business of the kinds you ask for around a point, nearest first, each with its opportunity score from 0 to 100 and the reasons behind it: the same facts and weights as a scan in the app.

BodyTypeWhat it is
latnumbernumberRequired. Latitude of the centre, like 45.5231
lngnumbernumberRequired. Longitude of the centre, like -73.5817
radius_mintegerintegerRequired. The radius in metres, from 100 to 5,000
categoriesstring[]string[]Optional. Kinds of businesses: dentist, restaurant, cafe, gym, salon, spa, auto, plumber, hvac, roofing, law, realestate, vet, clinic, chiro, bakery, retail, hotel. Leave it out for all 18
limitintegerintegerOptional. At most 500 businesses
curl -X POST https://radiuspilot.com/api/v1/businesses/search \
  -H "Authorization: Bearer $RADIUSPILOT_API_KEY" \
  -H "Content-Type: application/json" \

BodyTypeWhat it is

languagestringstringOptional. A language code, like "en" or "fr"

Errors

An error has an HTTP status and a body with a short code to test against and a message to read:

Answer · 402
{
  "error": {
    "code": "not_enough_credits",
    "message": "This request needs 10 credits, and 4 are left."
  }
}
StatusCodeWhat happened
400invalid_requestA field is missing, has the wrong type or is out of range
401unauthorizedNo key, a mistyped key or a revoked one
402not_enough_creditsThe request needs more credits than are left. Nothing is spent
403beta_onlyThe account isn’t an accepted beta tester yet
404not_foundNo such endpoint
429rate_limitedOver the key’s limit. Retry-After says how many seconds to wait
502upstream_failedA service behind the request didn’t answer. Its credits are given back
503server_busyA daily limit on our side is reached. Try again later
503not_configuredThat part of the API isn’t switched on yet

Limits

  • 30 requests a minute and 1,000 a day, per key. Past either one: 429 rate_limited, with Retry-After in seconds.
  • RadiusPilot AI keeps its own daily limits on our server. When one is reached, ai/write and ai/report answer 503 server_busy until later.
  • During the beta, business searches also share a daily cap across every key. Past it, businesses/search answers 503 server_busy.
  • Credits a busy or failed request didn’t use stay on your balance.

What it never returns

  • Google data. Google’s terms don’t allow passing it on, so Verify listing stays in the app.
  • Email addresses. Collecting addresses in bulk with software goes against Canada’s anti-spam and privacy laws, so the API never does it.
  • What a site hides from robots. A site check reads the homepage as a visitor sees it, and never decodes a hidden address.
  • Ratings, reviews or rankings. Public listings don’t have them, and RadiusPilot never makes them up.

The data licence

Business data comes from public listings shared under an open licence, which asks for a credit wherever the data is shown. Every search answer carries it in attribution. Show it next to the data, as RadiusPilot’s exported reports do.

In every search answer
"attribution": "© OpenStreetMap contributors (ODbL)"

Read the licence and how to give the credit

Drafts and anti-spam law

ai/write writes a draft. It never sends anything, and what you send is up to you:

  • Email a business only with its consent, express or implied, as Canada’s anti-spam law (CASL) asks for email received in Canada.
  • Add your business name, your postal address and a working way to unsubscribe. RadiusPilot’s own outreach adds them for you; a draft from the API doesn’t.
  • Read it before it goes out: it’s AI-generated and can be wrong.

See Email rules and the CASL guide. Not legal advice.
